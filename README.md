# AETHER UI

Repository scaffold only. Source files are intentionally empty placeholders so the project structure is ready for a clean upload.

## Structure

- `build/` — generated bundle output
- `src/` — framework source modules
- `src/Components/` — individual UI components
- `tools/` — build and audit scripts
- `tests/` — test suite

Run `python tools/bundle.py` after adding the source modules to generate `build/AetherUI.lua`.
